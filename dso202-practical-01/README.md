# DSO202 Practical 01

This practical demonstrates basic Kubernetes concepts such as namespaces, resource quotas, deployments, services, and client pods.

## Structure
- cluster/
- manifests/
- evidence/
- report/

## Usage
1. Create the Kind cluster using the manifest in cluster/kind-cluster.yaml.
2. Apply the manifests under manifests/.
3. Capture evidence in evidence/.
4. Write the report in report/practical-01-report.md.
